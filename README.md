## 🌟 Key Highlights & Features

- **🌓 Dark & Light Theme**: Seamless theme toggling with persistent user preference storage in `localStorage`.
- **✨ Glassmorphic UI & Aurora Typography**: Clean frosted glass design with dynamic gradient shift effects and floating tech badges.
- **🎯 Interactive Custom Cursor**: Fluid lag-free custom cursor with magnetic hover states on interactive controls.
- **📱 100% Responsive Design**: Carefully optimized for all viewports (Mobile, Tablet, Laptop, and 4K Desktop) with zero horizontal overflow.
- **📑 Dedicated Case Studies**: In-depth, client-ready case study pages with architectural workflows, problem/solution breakdowns, and interface galleries.
- **📬 Functional Contact System**: Direct email messaging powered by EmailJS client SDK with honeypot spam protection and instant validation.
- **⚡ Fast & Accessible**: Semantic HTML5, accessible ARIA attributes, skip-to-content links, and zero heavy framework overhead.

## 💻 Local Development

To run or preview this portfolio locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AnkushRana01/Portfolio.git
   cd Portfolio
   ```

2. **Open directly in browser:**
   - Double-click `index.html` or open via VS Code Live Server / any local static server:
   ```bash
   npx serve .
   ```

3. **View UpStack Case Study:**
   - Navigate to `projects/upstack/index.html` directly or click **Case Study** on the UpStack project card.
